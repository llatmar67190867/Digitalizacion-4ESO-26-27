# Formularios y cuestionarios 
En este apartado voy a explicar los Formularios de Google, cómo funcionan y lo que hemos tenido que realizar en esta práctica. Bueno los formularios de Google son una herramienta web. Forma parte de Google Workspace y del conjunto de editores web de Google, y las respuestas pueden enviarse automáticamente a Hojas de cálculo de Google. Para acceder a su página principal, debemos iniciar sesión con nuestra cuenta de Google (en este caso con la de educaand) y acceder al siguiente enlace: [docs.google.com/forms](docs.google.com/forms)

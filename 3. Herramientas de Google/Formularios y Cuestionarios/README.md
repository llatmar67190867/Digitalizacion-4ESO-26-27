# Formularios y cuestionarios 
En este apartado voy a explicar los Formularios de Google, cómo funcionan y lo que hemos tenido que realizar en esta práctica. Bueno los formularios de Google son una herramienta web. Forma parte de Google Workspace y del conjunto de editores web de Google, y las respuestas pueden enviarse automáticamente a Hojas de cálculo de Google. Para acceder a su página principal, debemos iniciar sesión con nuestra cuenta de Google (en este caso con la de educaand) y acceder al siguiente enlace: [docs.google.com/forms](docs.google.com/forms)

## Herramientas utilizadas
Cuando accedemos a la página, debemos crear un formulario en blanco, el cual vamos a transformar en un cuestionario autocorregible. Para ello, antes de empezar con las preguntas, activamos y comprobamos las siguientes opciones: 

| Opción | Utilidad |
| --- | --- |
| `Convertir en un cuestionaio y publicar calificaciones más tarde de la revisión manual` | Asignar puntuaciones, definir respuestas y proporcionar comentarios automáticamente. Si enviamos las calificaciones más tarde, debemos revisar las respuestas que no son autocorregibles. |
| `Preguntas respondidas de manera incorrecta` | Los encuestados pueden ver las preguntas que respondieron de forma incorrecta |
| `Respuestas correctas` | Los encuestados pueden ver las respuestas correctas una vez que se publican las calificaciones |
| `Puntuaciones` | Los encuestados pueden ver la puntuación total y los puntos recibidos con cada pregunta |
| `Recopilar direcciones de correo electrónico (Verificadas)` | Los encuestados deberán iniciar sesión en Google |
| `Limitar a 1 respuesta` | Así será modelo examen, no podrán modificar la respuesta |
| `Marcar las preguntas como obligatorias de manera predeterminada` | Aunque todas las preguntes se marquen como obligatorias, podemos modificarlo e indicar que no son obligatorias |

Existen otras opciones en los ajustes, pero estas son las mejores para transformar esto en cuestionario.

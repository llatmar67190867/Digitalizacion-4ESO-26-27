GIMP (Acrónimo de GNU Image Manipulation Program) es un programa libre, gratuito y de código abierto para crear y editar imágenes digitales de mapa de bits. Funiona en diferentes sistemas operativos, tales como Windows, MacOS y Linux (nosotros la utilizamos con una distribución de Linux llamada EducaandOS, creada por la Junta de Andalucía), que digamos que son los más conocidos. Como ejemplos de uso, tenemos:

**• Retoque y edición fotográfica:** corregir color e iluminación, recortar, ajustar escala o quitar imperfecciones.

**• Composiciones y diseño:** trabajar con capas y máscaras, crear fotomontajes, logotipos, ilustraciones o GIF animados.

**• Pintura y dibujo digital:** usar pinceles, herramientas de selección, filtros y tabletas gráficas.

**• Conversión y automatización:** exportar y convertir formatos (como XCF, PNG, JPG, PSD, PDF o SVG) y automatizar tareas con complementos o scripts
